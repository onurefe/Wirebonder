\begin{wbwarning}
\textbf{The height parameters accept values the Z axis cannot reach.} The
editor allows \menuitem{Reset Height}, \menuitem{Loop Height},
\menuitem{Search 1}, \menuitem{Search 2} and \menuitem{Second Z Hgt} up to
20\,mm, but the axis has only 9\,mm of travel. A height above roughly 9\,mm is
commanded, never arrives, and the cycle fails with \msg{Z POS. NOT SETTLED} or
\msg{TIMEOUT}.

Keep every height comfortably inside 9\,mm. If a cycle times out on a move and
the path is clear, check the heights first.
\end{wbwarning}

against the machine as built rather than assuming the original figure.
